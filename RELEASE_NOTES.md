Multi Codex profiles, launchers, and a native connection chooser.

- Permanent curl installer and compiled CLI, with no Node requirement.
- Guided count; add and rename profiles later; update without losing sign-ins.
- macOS card chooser, exact-process delivery, colored Dock launchers, and adoption of existing profiles.
- Experimental Windows WPF and Linux Tk adapters; desktop routing is not yet runtime-verified there.
