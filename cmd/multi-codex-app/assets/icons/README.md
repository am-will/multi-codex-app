# Profile icons

Five backgrounds: white, yellow, blue, purple, and teal. The Blossom mark uses dark lines on the light backgrounds and white lines on the dark backgrounds; every pairing exceeds 4.5:1 contrast.

The OpenAI Blossom path is from the official [OpenAI developer site](https://developers.openai.com/) navigation logo (retrieved October 7, 2026). Its geometry is unchanged. OpenAI owns this mark; it is not covered by this project's MIT license. See [OpenAI's design guidelines](https://openai.com/brand/). These icons identify local Codex profile launchers; they are not the project's logo or an endorsement.

SVGs are the vector sources. PNGs are 1024px exports. ICOs contain PNG frames at 16, 32, 48, 64, 128, and 256px. macOS generates ICNS variants during setup. Background/foreground values live in palette.json.
